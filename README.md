# Future Tires Trading LLC — Landing Page

Premium, conversion-focused landing page for **Future Tires Trading LLC**, a tyre shop in Al Quoz, Dubai.

**Live site:** https://jakewhite-ui.github.io/future-tires-landing/

## Features

- ⚡ Single self-contained `index.html` (inline CSS + JS, no build step)
- 🌙 **Dark / light theme** toggle (persisted in `localStorage`)
- 🌐 **English / العربية** toggle with full RTL support and Cairo Arabic font
- 📸 Photo-driven hero, service cards, About split and gallery (real automotive photos in `/img`)
- 📊 Animated stat counters, brand grid, FAQ accordion
- ⭐ Real Google rating (3.9 · 541 reviews) and real customer reviews
- 📞 Click-to-call, quote form, embedded Google Map
- 📱 Fully responsive (mobile-first), SEO + Open Graph tags, reduced-motion friendly
